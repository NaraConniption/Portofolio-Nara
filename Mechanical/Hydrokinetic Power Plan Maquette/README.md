# Hydrokinetic Power Plant (PLTHk) Maquette

**Supervised by:** Dr. Ridho Hantoro | **Year:** 2024

## Overview
Built a scaled prototype of a hydrokinetic turbine power plant using a floating catamaran pontoon foundation.

## Key Features & Contributions
* **Scaled Prototype:** Designed and constructed a hydrokinetic power plant model using a stable catamaran pontoon structure.
* **HMI & Simulation Integration:** Integrated with a Nextion Human-Machine Interface (HMI) to enable real-time model simulation across various flow velocities.

# Machine Learning & AI Energy Projects
**Nara Pangestu Apramada** | *Applied Machine Learning & Energy Software*

Repositori ini memuat implementasi *machine learning* (ML), *deep learning* (DL), dan pengembangan platform perangkat lunak terintegrasi AI untuk aplikasi energi terbarukan, pemantauan sistem, serta kalkulasi emisi industri.

---

## 📌 Daftar Proyek & Riset

### 1. [LSTM-RNN for PLTS Performance Prediction] (Skripsi)
* **Deskripsi:** Pengembangan model *Deep Learning* berbasis LSTM-RNN untuk memprediksi efisiensi dan performa pembangkit listrik tenaga surya (PLTS) berdasarkan dinamika cuaca. Hasil estimasi diintegrasikan ke dalam visualisasi *Virtual Reality* (VR) untuk pemantauan interaktif.
* **Scope & Pipeline:**
  * End-to-end ML pipeline: pembersihan data, *feature engineering*, pelatihan model, dan evaluasi performa *multi-target*.
  * Integrasi data *time-series* untuk analisis efisiensi harian dan estimasi luaran daya.
* **Tech Stack:** Python, TensorFlow / Keras, Scikit-Learn, VR Visualization.

### 2. [EMITRA – AI-Assisted Industrial Emission Calculator](Underdevelopment)
* **Deskripsi:** Platform perangkat lunak terintegrasi AI untuk menghitung emisi Gas Rumah Kaca (GRK) industri dalam rangka pemenuhan standar kepatuhan PROPER.
* **Fitur Utama:**
  * Klasifikasi dan kalkulasi emisi otomatis untuk **Scope 1, Scope 2, dan Scope 3**.
  * Engine perhitungan emisi sesuai standar regulasi dan generator laporan otomatis.
* **Tech Stack:** Python, Machine Learning Engine, React, Tailwind CSS, Firebase.
